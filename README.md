# RSCP-docs

Documentation for the [RSCP programming language](https://github.com/LavaKot/RSCP):
tutorials, the language tour, grammar and reference.

**Rendered as a website:** <https://lavakot.github.io/RSCP-docs/>

## Contents

* [index.md](index.md) — the landing page (tutorials, install, bugs)
* [tutorial.md](tutorial.md) — the language tour
* [builtins.md](builtins.md) — built-in functions and operators
* [grammar.md](grammar.md) — the full EBNF and semicolon-insertion rules
* [errors.md](errors.md) — errors, exit codes and implementation limits
* [compare.md](compare.md) — RSCP vs Python vs Rust

## Contributing

Found a typo or something unclear? Open an issue or a pull request — the
pages are plain Markdown. Bug reports for the language itself go to the
main repository: [LavaKot/RSCP/issues](https://github.com/LavaKot/RSCP/issues).
